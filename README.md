# 零跑智控

[![GitHub 最新 Release](https://img.shields.io/github/v/release/stephenwang1011/leapauto?label=GitHub%20Release)](https://github.com/stephenwang1011/leapauto/releases/latest)

零跑智控是一款基于 Kotlin、Jetpack Compose 构建的非官方零跑汽车 Android 车况与远程控车应用，专为个人学习与日常自用车主打造。直接对接零跑官方服务接口，实现高响应度车况读取、全套安全控车与无感近场钥匙。

> **免责声明**：本项目为非官方个人开源项目，不代表零跑官方。仅供个人技术研究与日常用车便利，请在确认车辆周围环境安全的前提下使用远程控制功能。

---

## 项目亮点

- **智能座舱·真微晶毛玻璃（Liquid Crystal Glassmorphism）**  
  双对角微晶渐变、高光切边与环境极光折射，采用 Compose Canvas/Brush 渲染；交付安装包设置 10 MiB 大小门禁。
- **纯电 / 增程双动力深度适配**  
  智能识别硬件信号与车型配置：纯电车型显示单电量槽与纯电续航；增程车型自适应呈现油电双续航看板、油量与电量双进度条，支持手动与智能预选动力模式。
- **BLE 无感蓝牙车钥匙**  
  集成低功耗蓝牙车钥匙，支持近场扫描、SM2 国密握手鉴权和本地蓝牙锁控；具体能力取决于车型、钥匙授权及手机后台权限。
- **桌面小组件与系统级快捷操作**  
  提供 4x2 经典小组件与紧凑型小组件，支持 4 档微晶透明度切换与快捷控制槽位自定义；集成 Android 下拉控制中心快捷设置磁贴（Quick Settings Tiles），控车触手可及。
- **本地硬件安全与隐私保护**  
  4 位操作密码与凭证使用 Android Keystore 管理的密钥加密保存。控车时操作密码按协议加密后发送；启用道路位置解析时会向地图服务请求地址，外部导航由用户主动触发。

## 核心功能

### 1. 远程控制矩阵
- **车身与门锁**：车门上锁/解锁、前备箱开闭、后备箱开闭、天幕遮阳帘开闭；
- **车窗微调**：车窗通风、车窗半开、车窗全关，以及车窗开合百分比滑动调节；
- **智能安防**：鸣笛寻车、开启/关闭哨兵模式、未关门窗异常实时提醒；
- **空调温控**：空调一键启停、16~32°C 精准温度调节、极速制冷、极速制热、前挡除霜除雾、快速除味；
- **舒适座舱**：主驾/副驾座椅加热与通风（0~3档）、后排座椅加热/通风、方向盘加热、后视镜加热、车载冰箱控制（冷藏/冷冻/保温、急速/标准、离车保持）；
- **充放电管理**：开始/停止充电、解锁充电枪、预约充电计划、健康充电电量上限设定（如80%/90%限制）、电池预热。

充电操作在抽屉内展示处理中、执行结果或待确认状态。充电结束且电量为 100% 时显示“已充满”，低于 100% 时显示“充电已停止”；剩余时间为零不作为充满依据。远程功能是否可用取决于车型配置、账号权限和车辆状态。

### 2. 车况与能耗中心
- **实时车况**：车内外温度、总里程、车速、挡位、四轮胎压与胎温监测；
- **续航看板**：纯电续航、燃油续航（增程）、SOC 百分比、实时充电功率/电压/电流及充满预估倒计时；
- **能耗统计**：近7天行驶里程折线图（支持今天/昨天智能相对日期）、周度电耗趋势曲线、能耗构成分析（行车/空调/其他）；
- **位置感知**：高德 Web 逆地理道路地址解析（支持专属 Key 配置与熔断自愈）、地库底盘停车照片寻车、一键调起外部地图导航（高德/百度/腾讯/系统地图）。

## 📖 用户使用指南

### 1. 登录与安全鉴权
- **账号登录**：输入零跑绑定手机号，获取短信验证码直接登录；
- **4位控车密码**：远程控车需要您在零跑官方 App 上设置的 **4 位数字操作密码**；本地加密保存，构造控车请求时按协议加密后随请求发送。

### 2. 桌面小组件配置
- **添加组件**：在手机桌面长按空白处 -> 点击「添加微件/小组件」-> 找到「零跑智控」，添加 **4×2 大组件** 或 **2×2 紧凑小组件**；
- **个性化设置**：打开 App -> 首页右上角齿轮 ->「设置」：
  - **背景风格**：支持「微晶毛玻璃」与「原厂主题实景皮肤」切换；
  - **透明度调节**：经典微晶风格支持 100%、75%、50%、25% 四档通透度调节；
  - **自定义按钮**：通过「4×2 插件快捷按键」配置底部快捷操作；
  - **显示适配**：提供深浅色文字与背景适配。

### 3. 下拉通知栏控制中心磁贴（Quick Settings）
- **一键快捷控车**：下拉手机状态栏控制中心 -> 点击「编辑」按钮 -> 将「车锁」、「空调」、「寻车」磁贴拖入常用面板；
- **自适应反馈与防抖**：车锁磁贴支持上锁/解锁状态自适应切换，内置 15 秒云端延迟防回退保护与指令并发防丢保护。

### 4. 爱车主图与 3D 沉浸式展台
- **主题切换**：进入「设置」->「主题中心」。支持 3D 的车辆可选择「层峦叠嶂」「雾川雪境」「余晖石筑」「晴空广场」等主题，具体列表以页面为准；
- **无 3D 资源车辆**：使用原厂 2D 车图，可选择「原厂默认」浅深色自适应背景或内置「雾川雪境」，首页与小组件同步。没有已保存偏好时默认原厂外观，已有偏好继续沿用；
- **自定义主图**：在「爱车主图定制」中可从相册上传个性化爱车抠图（如战舰/超跑），或随时一键「恢复官图」。

### 5. 高德地图位置解析（专属 Web Key）
- **道路位置反查**：通过高德 Web 服务将车辆坐标解析为道路地址，服务可用性取决于网络和 Key 配置；
- **配置指南**：进入「设置」->「高德 Web 服务配置」，填写自己的 Web 服务 Key；额度与使用条件以高德开放平台当前规则为准。

### 6. 车机系统 OTA 升级管理
- **固件检测**：进入「设置」->「车机系统 OTA」，查询是否有适用于当前车辆的系统推送；
- **全流程管控**：支持查看完整更新日志、远程推送下载、立即安装或**预约夜间闲时自动升级**（车主主账号专属功能，严格遵循车端安全门禁）。

### 7. BLE 蓝牙数字钥匙
- **近场直连控车**：进入「设置」->「蓝牙数字钥匙」，按页面提示完成钥匙配置；就绪后可使用本地蓝牙锁控；
- **使用建议**：为杜绝与官方零跑 App 后台争抢蓝牙信道引起断连，建议在使用前确认蓝牙后台权限，日常亦可搭配手机系统自带 NFC 钥匙配合使用。

### 8. 多座驾切换与动力模式
- **多车管理**：名下拥有多台零跑时，可通过车辆选择入口切换座驾，车辆配置与车模缓存按车辆管理；
- **动力模式自适应**：在「动力模式设置」中支持纯电（单电量槽与纯电续航）与增程（油电双续航与双进度条）模式自由切换。

### 9. 检查更新与安全退出
- **应用更新**：在设置的版本信息中检查更新，下载后按 Android 系统提示确认安装；
- **退出登录**：清除本地会话凭据与操作密码，设备偏好单独保留。

### 10. 支持作者
- 仅保留「设置」中的「支持作者」手动入口，登录后不再自动弹出提醒。

## 快速上手与本地构建

### 环境要求
- Android Studio Ladybug / Koala 或更高版本
- JDK 17
- Android SDK Platform 35

### 编译与测试
在项目根目录下通过 PowerShell 执行：

```powershell
# 执行全量单元测试，数量与结果以本次报告为准
.\gradlew.bat :app:testDebugUnitTest

# Release 编译验证
.\gradlew.bat :app:assembleRelease

# 代码与资源静态检查
.\gradlew.bat :app:lintRelease
```

单测报告位于 `app/build/reports/tests/testDebugUnitTest/index.html`。需要交付安装包时，在全量单测通过、配置本地签名后运行 `./scripts/package-release.ps1`；产物位于 `app/build/distributions/release/零跑智控-<版本>.apk`，不使用 Debug APK 作为交付包。
