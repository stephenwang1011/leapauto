# 零跑智控 · 全局设计规范 (Design Specifications)

> **设计基准**：智能座舱级·真微晶毛玻璃（Liquid Crystal Glassmorphism）  
> **适用范围**：零跑智控（LeapAuto）Android 客户端所有现有及新增界面、弹窗、抽屉与桌面小组件  
> **核心原则**：通透（Translucent）、克制（Restrained）、精密（Precise）、高效（Efficient）

---

## 1. 核心设计哲学与风格定调 (Design Philosophy)

本设计规范融合了**高端智能新能源座舱（如蔚来 Banyan / 特斯拉 / 理想）的仪表盘工业美学**与 **现代微晶玻璃光学流体哲学**：

1. **真微晶毛玻璃（不是廉价半透明塑料）**：
   - 抛弃单调扁平的纯色半透明色块，采用对角流光渐变多阶透镜材质。
   - 具备物理级微晶切边高光（Specular Rim Light）与顶层 0.5dp 水切横向折射线，营造双层钢化玻璃般的悬浮立体感。
2. **环境极光动态折射（Ambient Aura Refraction）**：
   - 玻璃是活的折射体：在卡片底层埋设极淡的环境极光，根据车辆状态（电池健康度、空调冷热、预警级别）进行微透呼吸，赋予界面生命感。
3. **仪表盘级精密排版（Dashboard Precision）**：
   - 模块化微晶胶囊对齐结构，严格的 2~3dp 字符吸附间隙与黄金信息阶级，杜绝松散与错位。
4. **安全与性能第一（Zero-Cost & Safe）**：
   - 不引入任何高开销的动态重度高斯模糊库（如 RenderEffect/模糊贴图），100% 依赖 Compose 纯硬件加速矢量 Canvas 绘制，保证低端机型稳定 60/120 FPS。
   - 保持严格的文字无障碍对比度（WCAG AA）。

## 2. 色彩体系规范 (Color System)

### 2.1 中性基础色与状态语义色
全 App 以黑白灰为基础界面色，保留高辨识度状态语义色。主操作、普通选中态、链接与扫描效果不再使用蓝色，严禁引入与车况竞争的高饱和霓虹色彩：

| 语义色彩 | 色值代码 | 透明度建议 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **中性主色 (Primary)** | 浅色 `#303030` / 深色 `#E4E4E4` | 使用实色文字和图标，浅层底色依主题控制 | 主行动点、普通选中态、导航、测距点、指南强调 |
| **能量生态绿 (Energy Green)** | `#00C853` | `0.08f ~ 0.15f` (极光晕) | 已确认开启、正常能量状态、健康充电中、100分健康体检、操作成功 |
| **警示安全红 (Alert Red)** | `#FF3B30` | `0.12f ~ 0.20f` (警示光晕) | 胎压报警、车门未锁、系统故障、危急提示 |
| **暖调预警橙 (Warning Amber)**| `#FF9500` | `0.12f ~ 0.18f` (微光) | 低温预警、电量偏低、需留意提醒 |

- 主色实心按钮必须配套 `onPrimary`：浅色模式白字，深色模式 `#202020` 深灰字；普通文本使用 `onSurface` / `onSurfaceVariant`，禁止将深色模式的浅灰主色与白字搭配。
- 已确认生效状态使用绿色；发送中、等待回包、状态未知以及仅本地选中均不得显示为已生效。保留禁用、加载、错误与确认反馈的可区分性。
- 设置卡片、公共控件、通知与桌面插件统一使用中性基础色；玻璃渐变、边框高光与层次保留，移除蓝色底色、蓝色光晕和蓝绿装饰渐变。
- 设置模块已有的标题图标允许使用分类点缀色：主题紫、钥匙琥珀金、支持作者玫瑰红、开源墨绿、OTA 青绿、版本灰紫。仅用于图标及 12% 同色圆底，深浅模式分别适配，保持至少 3:1 图标对比度。标题、卡片、按钮与箭头仍使用中性色；高德配置及 OTA、版本检查的已有成功、提醒、失败状态色优先，不将分类色用作已生效状态。
- 能耗等多类别图表保留类别区分，采用非蓝色配色并配合标签，不将所有类别合并为同一灰色。天气图标采用中性图标与状态色。
- 车辆照片、主题背景图片与 3D 原始素材中的自然蓝色不属于界面强调色，本次不改色或替换素材。

首页深色模式的告警前景按承载背景区分：快捷操作文字与图标使用 `#FF3B30`，车况、胎压等信息区域使用 `#FF8A80`，兼顾红色辨识度与小字对比度。仅替换告警前景，保留原有背景、边框与光晕；其他页面及浅色模式沿用既有主题配色。

首页底部快捷操作栏按 App 深浅模式匹配页面过渡底色；上方展台信息独立按主题背景判定文字对比度。石筑浅色模式的快捷栏使用浅色按钮与深色图标、文字，不能沿用上方展台的白字样式。

石筑浅色模式的昵称及设置图标使用近黑色 `#202020`，更新时间与天气使用深灰 `#404040`，续航数字和 km 单位使用白色以适配所在背景。位置、驻车、充电中心胶囊保持原有深底白字，电量状态色不变；石筑深色模式与其他主题仍沿用原有背景对比度规则。

晴空广场浅色模式的 km 单位使用与正常电量百分比一致的绿色 `#00B42A`，适配单位所在的深色背景区域；续航数字与其他文字仍沿用原配色，深色模式不受此规则影响。

### 2.2 背景与微晶玻璃色盘
必须适配深色（Dark）与浅色（Light）双模原生系统夜间模式：

| 材质层级 | 浅色模式 (Light) | 深色模式 (Dark) | 视觉特性 |
| :--- | :--- | :--- | :--- |
| **全局画布背景** | `#E8E8E8`（中性浅灰） | `#111111`（中性深灰） | 纯净底衬，衬托玻璃浮空 |
| **微晶卡片起始色** | `Color(0xFFFFFFFF).copy(0.88f)` | `Color(0xFF292929).copy(0.82f)` | 左上角迎光面，透亮坚挺 |
| **微晶卡片中心色** | `Color(0xFFF8F8F8).copy(0.72f)` | `Color(0xFF202020).copy(0.70f)` | 中心透镜区，透出底层极光 |
| **微晶卡片终止色** | `Color(0xFFFFFFFF).copy(0.82f)` | `Color(0xFF181818).copy(0.80f)` | 右下角背光面，沉稳收敛 |

首页夜间承载层沿用独立的 `HomeNightStyle`：页面底色 `#1D1D1D`，卡片按 `#373737`（0.90f）、`#2E2E2E`（0.86f）、`#282828`（0.90f）渐变，以保持复杂主题背景上的文字可读性；不与通用玻璃色盘混用。

## 3. 微晶毛玻璃标准实现范式 (Implementation Paradigms)

### 3.1 核心修饰符：`Modifier.frostedGlassCard`
所有卡片必须挂载该修饰符，以统一赋予对角渐变底板、环境极光与顶层微折射晶线：

```kotlin
@Composable
internal fun Modifier.frostedGlassCard(
    shape: Shape = RoundedCornerShape(16.dp),
    auraColor: Color? = null,
    auraCenter: Offset = Offset(0.2f, 0.2f),
    auraRadiusRatio: Float = 0.45f,
    topSpecularLine: Boolean = true
): Modifier
```

#### 常见场景 Aura 极光搭配建议：
* **爱车卡片 (`VehicleHero`)**：默认使用中性灰白材质；正常能量状态可传入 `statusGood` 微光（alpha 0.08f~0.15f）；
* **空调卡片 (`ClimateOverviewCard`)**：默认使用中性灰白材质，已确认开启使用 `statusGood.copy(0.10f)`；未知、执行中和未开启不使用绿色生效光晕；
* **能耗卡片 (`EnergyHomePagerCard`)**：传入能量绿微光 `statusGood.copy(0.10f)`；
* **胎压卡片 (`HomeTirePressureCard`)**：异常告警使用红色微光，需留意提醒使用暖橙光，平时纯净无极光。

---

### 3.2 物理级微晶切边高光：`glassCardBorder()`
卡片边框必须统一使用 3 阶渐变反光线，严禁使用纯色硬描边：

```kotlin
@Composable
internal fun glassCardBorder(): BorderStroke {
    val isDark = LocalAppDarkTheme.current
    val topLeftColor = if (isDark) Color.White.copy(alpha = 0.32f) else Color.White.copy(alpha = 0.88f)
    val middleColor = if (isDark) Color.White.copy(alpha = 0.12f) else Color.White.copy(alpha = 0.45f)
    val bottomRightColor = if (isDark) Color.White.copy(alpha = 0.05f) else Color.White.copy(alpha = 0.20f)
    return BorderStroke(
        1.0.dp,
        Brush.linearGradient(
            colors = listOf(topLeftColor, middleColor, bottomRightColor),
            start = Offset.Zero,
            end = Offset(Float.POSITIVE_INFINITY, Float.POSITIVE_INFINITY)
        )
    )
}
```

### 3.3 弹窗规范：`solidDialogModifier()` 与高对比度纯实色背景 (Solid High-Contrast Dialogs)
**严禁弹窗与弹出层透明化！**
弹窗浮于复杂的车况界面之上，核心是确保信息阅读、密码输入与二次确认的绝对清晰。若弹窗采用半透明材质，底层的车辆、数字与图表会透过来与弹窗文字产生严重的视觉冲突与杂乱感。

统一规范：
- 容器底色：`containerColor = MaterialTheme.colorScheme.surface`（深色深黑、浅色纯白高对比度实心底色）；
- 边框修饰：`modifier = solidDialogModifier()`（带 0.8dp 精致物理微晶切边）；
- 容器圆角：`shape = RoundedCornerShape(24.dp)`，`tonalElevation = 0.dp`。

```kotlin
AlertDialog(
    onDismissRequest = onDismiss,
    modifier = solidDialogModifier(shape = RoundedCornerShape(24.dp)),
    containerColor = MaterialTheme.colorScheme.surface,
    tonalElevation = 0.dp,
    shape = RoundedCornerShape(24.dp),
    ...
)
```

---

### 3.4 抽屉面板规范：`ModalBottomSheet` 纯实色承载 (Solid BottomSheet)
所有上滑半屏抽屉面板（全车健康体检、充电中心、预约电池预热）必须采用高对比度纯实色背景（`containerColor = pageBgColor` 或 `MaterialTheme.colorScheme.surface`）：
- 严禁抽屉容器透明化，杜绝上滑时与底层首页车模或按钮产生穿透杂光；
- 抽屉内部承载的各功能独立小卡片（如体检 21 项微晶胶囊、充电工况卡片）可以保持微晶毛玻璃材质，以呈现丰富的纵深质感。

## 4. 排版与关键尺寸规范 (Typography & Metrics)

### 4.1 续航与电量核心数据组（纯电与增程一致）
为了呈现精密仪表感，首页卡片与桌面小组件的核心数字必须严格执行统一字号与间距：

| 元素项 | 字体大小 | 字重 (Weight) | 相对间距 / 样式 |
| :--- | :--- | :--- | :--- |
| **续航里程大字** | `26.sp` | `FontWeight.Bold` | 紧贴基准线，行高 `26.sp` |
| **里程单位 `km`** | `12.sp` | `FontWeight.Bold` | 距大字右侧 `3.dp`，底部对齐下沉 `1.5dp` |
| **精准电量百分比** | `13.sp` | `FontWeight.Bold` | 显示格式为 `· 74.6%`，距单位右侧 `3.dp` |
| **续航能量条宽度** | `110.dp` | — | 位于字符组下方 `2.dp` 处，左对齐 |
| **续航能量条高度** | `4.5.dp` | — | 圆角胶囊槽（圆角 `2.dp`），带能量高光填充 |

### 4.2 全局圆角阶梯法则
* **超大容器 / 主卡片 / 底部抽屉顶部**：`20.dp` ~ `24.dp`
* **信息单元卡片 / 快捷车控板 / 设置项**：`16.dp`
* **微晶分类项目胶囊 / 状态徽章 / 按钮**：`6.dp` ~ `8.dp`
* **圆形按钮 / 呼吸光点**：`CircleShape`

## 5. 动效与微交互规范 (Animations & Micro-interactions)

### 夜间主题背景亮度

- 设置 → 主题中心仅在深色模式显示“夜间背景亮度”，范围 10%～150%，标示较暗/较亮与当前百分比。百分比为背景处理参数，不代表屏幕亮度或实测光照。
- 雾川雪境默认 45%、余晖石筑 50%、晴空广场 45%、层峦叠嶂 50%；未知主题默认 100%。主题分别存储，主题 4 的 3D 天空盒与无 3D 原厂背景分开记忆。默认值用于未保存偏好或恢复默认，已有手动亮度保留；渲染换算基准独立于默认值，避免调整默认值改变已有亮度的效果。
- 拖动即时更新抽屉内本地预览，松手保存；取消拖动、切换主题/车辆、旋转、关闭抽屉或退出深色模式丢弃未完成草稿。恢复默认只清除当前主题偏好。首页通过偏好监听获取已保存值。
- 图片仅对背景应用 ColorMatrix；原生底色仅处理背景渐变；天空盒仅处理自身片元输出，禁止全场曝光、WebView 整体滤镜、车身或信息卡片变暗。预览不下载资源、不写车模快照、不调用车辆 API。
- 亮度调节标题与当前百分比使用主题 onSurface，较暗/较亮使用 onSurfaceVariant；当前百分比仅显示在预览上方，预览图不叠加重复数字或黑色底衬。滑条轨道为 4dp，保留至少 48dp 触控高度。快捷栏沿用底部深色地平线和文字阴影，不再给警告文字单独加矩形黑底。复杂画面及大字体效果需设备验收。
- 本地 3D 资源缺失时预览明确显示未就绪，不触发下载；无法识别的天空盒 shader 保持原样并提示不支持亮度预览。天空盒 shader 兼容性、实际帧率和触摸取消行为仍需实机验证。

### 5.1 全息雷达扫描（Holographic HUD Lidar）
全车健康体检扫描波必须遵循“晶锐细腻、不遮挡主体、无生硬色块”的原则：
1. **1.0 dp 晶白激光光刃**：纵向两端平滑透明羽化渐变（`startY=0f, endY=h`）；
2. **伴生中性灰白微光**：线宽控制在 `2.5.dp` 以内，保持微光轮廓，根据浅深色承载背景确保可见；
3. **双端全息测距光标**：在光线顶端和底端（`0.12h` 与 `0.88h` 处）随光束运动绘制微型菱形跟踪框与中心测距点；
4. **微粒子雷达点云拖尾**：后方伴随 8 颗带正弦物理微动的消散微粒；
5. **平滑全屏进出**：扫描比例范围设为 `-0.06f ~ 1.06f`，禁止在画面内突兀截断或闪烁重置。

### 5.2 触觉与按压弹性形变
* 可点击的重要卡片与快捷按钮在按压时具备微妙弹性响应（微缩放 `0.94f ~ 0.96f` + Spring 弹性回弹，配合轻微震动反馈 `LocalHapticFeedback`）。

## 6. 桌面小组件规范 (Desktop Widgets)

4x2 与 2x2 桌面小组件通过 XML Drawable 完美复刻微晶毛玻璃质感：
1. **315° 微晶磨砂对角流光渐变**：
   - 默认深色模式：`#E6303030`（左上）、`#D9252525`（中心）至 `#E61C1C1C`（右下）；
   - 默认浅色模式：`#F2FFFFFF`（左上）、`#E6F7F7F7`（中心）至 `#EDFFFFFF`（右下）；
   - 横向实景背景、25% / 50% / 75% 透明度及操作按钮使用对应 `widget_*` XML 资源中的中性渐变，保留各自透明度和层级，不强制覆盖为默认背景。
2. **高透切边高光线**：统一采用 `1dp stroke`（深色 `#4DFFFFFF`，浅色 `#B3FFFFFF`）。
3. **圆角必须统一**：所有小组件背景必须严格保持 `<corners android:radius="20dp" />`。
4. **参数对齐**：4x2 纯电车型的续航数值、单位 `km`、百分比及 `110dp×4.5dp` 能量槽与主 App 完全一致。

## 7. 架构红线与审查清单 (Hard Constraints Checklist)

后续任何新增界面、修改既有功能时，必须对照以下清单进行门禁自查：

- [ ] **严禁引入外部大体积毛玻璃库或 RenderEffect 实时模糊**（保证 10 MiB 包体限制与老设备流畅度）；
- [ ] **严禁在 Compose 页面中硬编码纯色无渐变大卡片**（必须通过 `frostedGlassCard` 赋予材质）；
- [ ] **严格使用主题中性主色与状态语义令牌**（使用 `MaterialTheme.colorScheme.primary`、配对 `onPrimary` 和 `MaterialTheme.statusGood` 等令牌，满足 `GlassSurfaceStyleTest` 约束；不得恢复蓝色界面强调或把未确认状态显示为绿色生效）；
- [ ] **严禁卡片设置 `shadowElevation > 0.dp` 产生的脏黑泥阴影**（通过微晶切边高光制造悬浮感）；
- [ ] **严禁弹窗（AlertDialog / Dialog）与上滑半屏抽屉（ModalBottomSheet）透明化**（必须使用 `containerColor = MaterialTheme.colorScheme.surface` 或 `pageBgColor` 高对比度纯实色背景，配合 `solidDialogModifier()` 微晶切边边框，确保文字绝对清晰不穿透）；
- [ ] **日常修改只执行相关模块测试，打包复用覆盖最终代码的有效通过结果；只有用户要求提交或推送代码时才执行全量单元测试**（`.\gradlew.bat :app:testDebugUnitTest` 100% SUCCESS 后才能提交或推送）。
