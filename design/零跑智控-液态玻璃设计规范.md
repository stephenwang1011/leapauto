# 零跑智控 · 液态玻璃（Liquid Glass）设计与实现规范

> **适用范围**：零跑智控（LeapAuto）Android 客户端  
> **设计基准**：融合 Apple iOS 26+ Liquid Glass 光学流体哲学与零跑汽车“科技·自然·年轻”设计语言  
> **技术框架**：Android Jetpack Compose (Material 3) + Android 8.0+ (API 26~35) 兼容标准

---

## 1. 设计哲学与融合原则 (Design Philosophy)

本规范旨在将 **Liquid Glass（液态玻璃）** 的光学质感与微动效引入零跑智控应用，并在 Android Jetpack Compose 架构下兼顾极佳的渲染性能与系统稳定性。

### 1.1 核心价值融合
1. **光学微透与环境反射 (Optical Translucency)**
   - 告别沉闷生硬的纯色灰块卡片，通过高透明度微晶表面透出底层车身背景与自然漫射光，营造通透、悬浮的轻盈质感。
2. **边缘微光与受光拟真 (Specular Edge Highlight)**
   - 模拟真实晶体边缘物理折射：卡片顶部受光边缘呈现 1dp 的细腻高光，底部逐渐收隐至微弱暗边，告别传统突兀的生硬描边与大阴影。
3. **流体张力与弹性响应 (Surface Tension & Micro-Bounce)**
   - 借鉴液态水滴的表面张力，交互组件在按压与释放时具备微妙的物理弹性形变（微缩放 0.96~0.98 + 低阻尼回弹），让远程控车操作具备生动自然的力触反馈。
4. **克制科技感 (Restrained Elegance)**
   - 严格遵循零跑品牌设计原则：**不使用夸张霓虹渐变、不使用破坏对比度的高饱和眩光、不过度拟物**。玻璃是承载车辆状态的容器，核心始终是“控车效率”与“行车数据可读性”。

## 2. 视觉材质与色彩令牌 (Visual Tokens)

### 2.1 玻璃表面层级 (Glass Layers)

| 材质层级 | 浅色模式 (Light Theme) | 深色模式 (Dark Theme) | 适用场景 |
| :--- | :--- | :--- | :--- |
| **底层画布 (Canvas)** | `#F5F6F9`（暖浅科技灰） | `#121418`（深邃曜石黑） | 全局背景、页面底衬 |
| **标准玻璃 (Regular Glass)** | `Color(0xFFFFFFFF).copy(alpha = 0.72f)` | `Color(0xFF1E222B).copy(alpha = 0.68f)` | 车况状态卡片、续航电量面板、行程详情 |
| **交互玻璃 (Interactive Glass)** | `Color(0xFFFFFFFF).copy(alpha = 0.88f)` | `Color(0xFF262C38).copy(alpha = 0.82f)` | 快捷控车按钮底座、胶囊筛选标签、Tab 激活态 |
| **突出玻璃 (Prominent Glass)** | `LeapBlue.copy(alpha = 0.12f)` | `LeapBlue.copy(alpha = 0.22f)` | 主操作按钮 (CTA)、一键极速制冷/制热、健康体检入口 |

### 2.2 晶体高光边框 (Specular Edge Border)

避免使用纯色 `BorderStroke`。统一采用垂直方向的双色线性渐变模拟顶部迎光面：

- **浅色模式边框**：
  ```kotlin
  Brush.verticalGradient(
      listOf(
          Color.White.copy(alpha = 0.65f), // 顶部微反光
          Color.White.copy(alpha = 0.15f)  // 底部隐入背景
      )
  )
  ```
- **深色模式边框**：
  ```kotlin
  Brush.verticalGradient(
      listOf(
          Color.White.copy(alpha = 0.18f), // 顶部冷光轮廓
          Color.White.copy(alpha = 0.04f)  // 底部过渡
      )
  )
  ```

### 2.3 语义与状态流动色调 (Status Tints)

将语义色注入玻璃材质，表现为浅饱和度的流体光晕而非纯实色覆盖：

- **品牌主色 (Leap Blue `#0066FF`)**：
  - 按钮激活、门锁解锁、蓝牙钥匙连接：采用 `0.10f` 浅色底透 + 1.2dp 蓝色高光边缘。
- **能源/健康 (Energy Green `#00C853`)**：
  - 正在充电中、电量满充、全车体检 100 分：浅绿色漫反射光斑 (`#00C853`, alpha = 0.08f~0.15f)。
- **告警/异常 (Alert Red `#FF3B30`)**：
  - 胎压异常、车门/车窗未锁闭：呼吸微光边缘 (`#FF3B30`, alpha = 0.25f)。

## 3. 几何形态与间距规范 (Geometric Rules)

1. **圆角阶梯一致性**：
   - **大型容器/主卡片 (Cards)**：统一采用 `20.dp` 连续曲率圆角。
   - **快捷控车按钮 / 操作胶囊 (Capsules & Controls)**：采用全圆角 `CircleShape` 或 `24.dp` 胶囊形。
   - **小型标签 / Badge**：采用 `8.dp` 或 `10.dp` 圆角。
2. **群组融合间距 (Container Spacing)**：
   - 相互关联的控制按钮（如锁车/开锁/车窗/后备箱）在同一 `Row` 中统一间距为 `12.dp`，视觉上呈现从同一整块晶体中切割分离的秩序感。
3. **修饰符顺序法则 (Modifier Order Mandatory Rule)**：
   - **先定形体与布局，后赋予玻璃材质**：
     ```kotlin
     // 正确示例：
     Modifier
         .fillMaxWidth()
         .padding(horizontal = 16.dp)
         .liquidGlass(...) // 放在尺寸/外边距之后，内边距与内容之前
         .padding(16.dp)
     ```

## 4. Jetpack Compose 标准实现范式

针对 Android 平台的性能优化，本规范提供纯原生 Compose 渲染方案（支持 API 26+，在 Android 12+ 自动支持硬件模糊增强，老系统依靠高精度渐变与多层透明度保持流畅 60/120 FPS）。

### 4.1 核心修饰符 `Modifier.liquidGlass`

```kotlin
package com.leapauto.app.ui.theme

import android.os.Build
import androidx.compose.animation.core.*
import androidx.compose.foundation.background
import androidx.compose.foundation.border
import androidx.compose.foundation.clickable
import androidx.compose.foundation.interaction.MutableInteractionSource
import androidx.compose.foundation.interaction.collectIsPressedAsState
import androidx.compose.foundation.layout.padding
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.material3.MaterialTheme
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.composed
import androidx.compose.ui.draw.clip
import androidx.compose.ui.draw.scale
import androidx.compose.ui.graphics.*
import androidx.compose.ui.unit.Dp
import androidx.compose.ui.unit.dp

/**
 * 零跑智控 液态微晶玻璃 Modifier
 */
fun Modifier.liquidGlass(
    shape: Shape = RoundedCornerShape(20.dp),
    tint: Color? = null,
    isInteractive: Boolean = false,
    onClick: (() -> Unit)? = null
): Modifier = composed {
    val interactionSource = remember { MutableInteractionSource() }
    val isPressed by interactionSource.collectIsPressedAsState()

    // 交互微按压回弹（液态表面张力微形变）
    val scale by animateFloatAsState(
        targetValue = if (isInteractive && isPressed) 0.96f else 1.0f,
        animationSpec = spring(
            dampingRatio = Spring.DampingRatioMediumBouncy,
            stiffness = Spring.StiffnessLow
        ),
        label = "liquid_glass_press_scale"
    )

    val isDark = MaterialTheme.colorScheme.background.luminance() < 0.5f

    // 基础玻璃透明填充
    val baseColor = if (isDark) {
        Color(0xFF1E222B).copy(alpha = 0.65f)
    } else {
        Color(0xFFFFFFFF).copy(alpha = 0.75f)
    }

    val finalBg = if (tint != null) {
        tint.copy(alpha = if (isDark) 0.18f else 0.10f).compositeOver(baseColor)
    } else {
        baseColor
    }

    // 晶体高光线性渐变边缘
    val borderBrush = Brush.verticalGradient(
        colors = if (isDark) {
            listOf(
                (tint ?: Color.White).copy(alpha = if (isPressed) 0.35f else 0.20f),
                (tint ?: Color.White).copy(alpha = 0.03f)
            )
        } else {
            listOf(
                (tint ?: Color.White).copy(alpha = if (isPressed) 0.85f else 0.65f),
                (tint ?: Color.White).copy(alpha = 0.15f)
            )
        }
    )

    this
        .scale(scale)
        .clip(shape)
        .then(
            if (isInteractive && onClick != null) {
                Modifier.clickable(
                    interactionSource = interactionSource,
                    indication = null, // 禁用传统波纹，保持晶体通透纯净感
                    onClick = onClick
                )
            } else Modifier
        )
        .background(finalBg, shape)
        .border(width = 1.dp, brush = borderBrush, shape = shape)
}
```

### 4.2 液态玻璃主卡片组件 `LiquidGlassCard`

适用于首页车况、剩余续航、空调状态、车辆位置等主要展示面板：

```kotlin
@Composable
fun LiquidGlassCard(
    modifier: Modifier = Modifier,
    shape: Shape = RoundedCornerShape(20.dp),
    tint: Color? = null,
    onClick: (() -> Unit)? = null,
    content: @Composable () -> Unit
) {
    Box(
        modifier = modifier
            .liquidGlass(
                shape = shape,
                tint = tint,
                isInteractive = onClick != null,
                onClick = onClick
            )
            .padding(16.dp)
    ) {
        content()
    }
}
```

        )
    }
}

## 5. 核心业务场景应用指南

### 5.1 爱车主屏（我的座驾）
- **车身与背景融合**：车身 2D 渲染图下方垫入微透的 `LiquidGlassCard`，透出轻微背景渐变，与车身阴影自然交融。
- **续航与电量面板**：采用带有 `EnergyGreen.copy(0.08f)` 微光底色的液态卡片，右侧剩余电量环采用高发光线条，卡片整体晶莹剔透。
- **横向快捷控车栏**：采用单行连续的圆形液态玻璃按钮底座，点击时伴随 0.96f 缩放弹性形变与触觉振动，操作确认感极强。

### 5.2 全车健康体检 (Health Check)
- **激光全息光束与玻璃折射**：体检进行时，全息扫描线扫过车身，下方的体检项卡片边缘高光随扫描节奏依次亮起，呈现光线穿越晶体的折射动效。
- **综合得分指示盘**：中心数字采用半透圆形玻璃衬底，根据得分（90+ 绿、70~89 蓝、<70 红）动态注入对应流体色。

### 5.3 充电与空调面板
- **充电状态**：根据充电功率动态调节玻璃底部的极光呼吸微光（微流光脉冲动画）。
- **空调温度胶囊**：调节温度时，极速制冷注入冰川蓝流光，极速制热注入暖红流光，滑动手感平滑紧凑。

## 6. 反模式与审查清单 (Anti-Patterns & Review Checklist)

在落地液态玻璃设计时，必须严格执行以下红线审查：

- [ ] **严禁滥用重度实时多层高斯模糊 (No Nested Heavy Blur)**：不要在可滑动列表中嵌套多层 `RenderEffect.blur`，必须使用纯色 Alpha 混合 + 渐变边框组合，确保低端机型不掉帧。
- [ ] **严禁丢失可读性 (No Readability Compromise)**：玻璃材质绝不能以牺牲文字对比度为代价。深色模式文字对比度必须保持在 WCAG AA 标准以上（重要文本透明度不低于 90%）。
- [ ] **严禁非交互元素乱动 (No Interactivity Abuse)**：纯信息卡片（如“总里程”）仅保留静态通透与边缘高光，不得添加按压缩放或触摸流光，避免视觉噪音。
- [ ] **严禁高饱和霓虹炫光 (No Neon Cyberpunk)**：底透光晕 Alpha 严格控制在 `0.06f ~ 0.22f` 之间，体现“克制、高级、自然”的零跑新能源美学。
- [ ] **必须保持无障碍与动效开关响应**：若系统开启了“减少动态效果（Reduce Motion）”，按压微缩放应自动降级为静态瞬时高亮反馈。
